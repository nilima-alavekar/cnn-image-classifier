# CNN Image Classification Application

A Deep Learning computer vision project using Convolutional Neural Networks (CNNs) to classify images and serve real-time predictions through an interactive Python web interface.

## Features
- Image preprocessing, resizing, and tensor normalization pipeline
- Trained Convolutional Neural Network (CNN) inference for image classification
- Interactive web application interface for uploading images and viewing predicted class labels

## Tech Stack
- **Language:** Python
- **Deep Learning & Vision:** TensorFlow / Keras, OpenCV, NumPy, Pillow
- **Web Interface:** Streamlit
